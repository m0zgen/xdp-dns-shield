# Security policy

## Supported versions

There is no supported release yet. The repository is in pre-release preparation
and must not be treated as a complete security control.

## Reporting a vulnerability

Do not open a public issue for a vulnerability that could expose deployments or
provide a practical bypass. Send a private report to the security contact that
will be published before the first source release.

Until that contact is listed, use the contact channel published on
[openbld.net](https://openbld.net/) and include `XDP DNS Shield security` in the
subject.

Please include:

- affected version or commit;
- deployment mode and relevant kernel/NIC details;
- impact and realistic attack prerequisites;
- minimal reproduction steps;
- whether disclosure is time-sensitive.

We will acknowledge a complete report, coordinate validation and remediation,
and credit the reporter unless anonymity is requested. Concrete response-time
targets will be published with the first supported release.
